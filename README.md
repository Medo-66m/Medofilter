# Medo Filter

## رفع المشروع على Vercel

ارفع الملفات دي كلها كما هي:

- index.html
- package.json
- api/parse.js

بعد الرفع، Vercel هيعمل install لمكتبة `xlsx` تلقائيًا.

## مهم

المشروع ده مش بيعتمد على روابط CDN في المتصفح لقراءة Excel.
قراءة ملفات Excel بتحصل من خلال `/api/parse` على Vercel، وده يحل مشكلة إن الملف يتحدد ومفيش حاجة تحصل.

## التجربة

1. افتح الموقع.
2. اختار ملف Excel أو اسحبه على منطقة الرفع.
3. انتظر الرسالة تحت مربع الأرقام.
4. لو فيه مشكلة، الرسالة هتظهر واضحة في المكان ده.
